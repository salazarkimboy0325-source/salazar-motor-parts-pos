# Salazar Motor Parts POS System

Point of Sale system for motor parts shop with inventory management, reports, and employee management.

## Features
- Inventory Management with categories
- Sales Processing (Cash, Card, GCash, Bank Transfer)
- Reports & Analytics
- Employee Management
- Debt Tracking
- Offline Support via Firebase
- Daily Summary Reports

## Setup

1. Clone this repository
2. Copy `firebase-config.example.js` to `firebase-config.js`
3. Replace the Firebase config with your own from Firebase Console
4. Open `login.html` to start

## Firebase Setup
1. Create a Firebase project at https://console.firebase.google.com
2. Enable Authentication (Email/Password)
3. Create Firestore Database
4. Copy your config to `firebase-config.js`
